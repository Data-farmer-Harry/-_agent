# Third-party runtime notices

MatterLab desktop installers assemble open-source scientific runtimes on the target build platform. This file is a notice, not a replacement for the complete license texts shipped by each dependency.

| Component | Runtime source | License / source |
| --- | --- | --- |
| LAMMPS | conda-forge on macOS; official 4Jul2026 Windows binary | GPL-2.0; https://github.com/lammps/lammps |
| FFmpeg | conda-forge | GPL-2.0-or-later build; https://ffmpeg.org |
| OVITO Python module | PyPI runtime dependency | GPL-3.0; https://gitlab.com/stuko/ovito |
| Python scientific packages | PyPI / conda-forge | Individual package licenses and source distributions |
| Electron | npm | MIT; https://github.com/electron/electron |

Before public binary distribution, preserve the license files included in the packed environment and complete a dependency-license review for the exact lock/build output.
